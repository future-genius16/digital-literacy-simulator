# Тренажер по цифровой грамотности

Веб-приложение для подготовки студентов к независимому экзамену по цифровой грамотности.

Проект представляет собой интерактивный тренажер с тренировочными заданиями, обратной связью, сохранением результатов и административной панелью для сопровождения банка вопросов.

---

## Возможности

Приложение включает две пользовательские роли: студента и администратора.

**Для студента** реализованы просмотр заданий независимого экзамена, прохождение тренировок по выбранным разделам, работа с вопросами разных типов, получение обратной связи после ответа и просмотр результатов подготовки.

**Для администратора** предусмотрена панель управления, позволяющая работать с пользователями, контролировать наполнение заданий НЭ, создавать и редактировать тренировочные вопросы, а также отключать неактуальные задания без удаления из базы данных.

**Банк заданий** поддерживает вопросы с одним правильным ответом, несколькими правильными ответами и задания на установление последовательности. Вопросы могут содержать изображения, пояснения и связанные учебные материалы.

**Техническая часть** включает контейнеризированный запуск через Docker Compose, автоматизированные тесты серверной и клиентской части, а также скрипт проверки корректности банка заданий.

## Установка и запуск через Docker

Для запуска приложения необходимо установить Docker Desktop.

### 1. Клонировать репозиторий

```bash
git clone https://github.com/future-genius16/digital-literacy-simulator.git
cd digital-literacy-simulator
```

### 2. Создать файл переменных окружения

Создайте файл `.env` на основе `.env.example`.

Пример переменных окружения:

```env
PORT=3001
DB_HOST=postgres
DB_PORT=5432
DB_NAME=digital_literacy
DB_USER=postgres
DB_PASSWORD=postgres
JWT_SECRET=your_jwt_secret
```

### 3. Запустить приложение

```bash
docker compose up --build
```

После запуска клиентская часть будет доступна в браузере:

```text
http://localhost:8080
```

Backend работает на порту:

```text
http://localhost:3001
```

PostgreSQL доступен на порту:

```text
5433
```

### 4. Проверить запущенные контейнеры

```bash
docker ps
```

В списке должны отображаться контейнеры frontend, backend и PostgreSQL со статусом `Up`.

### 5. Остановить приложение

```bash
docker compose down
```

## Запуск тестов

### Backend

```bash
cd backend
npm test
```

### Frontend

```bash
cd frontend
npm test
```

### Проверка банка заданий

```bash
cd backend
npm run audit:bank
```

Скрипт проверяет корректность банка заданий: наличие обязательных полей, типы вопросов, правильные ответы, изображения и распределение вопросов по заданиям независимого экзамена.
